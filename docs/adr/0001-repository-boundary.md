# Repository boundary

Status: accepted for local tooling construction.

FIELD-OPS-WITNESS owns repository validators now. Its planned responsibility is compact field reporting, source-bound health judgments, complete coverage, recall queries and a non-actuating health feed. It does not transport raw device payloads, instrument devices, actuate rollback or provide a hosted fleet server.

A local append-only report index is distinct from Ledger's global experiment lineage. Common representation and trust remain Toolkit-owned. Earlier expected inventory and actual installation observations constrain later coverage and recall.

The planned report identifier is separate from registered or qualified formats. Future changes must add genuine public producers and separate consumers, actual source qualification, complete negative cases, strict checks, tests, docs and native benchmark parity in the same complete change.
